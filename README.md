# Ali Allana English Medium School — website

Static website for AAEMS, Akkalkuwa. Plain HTML, CSS and JavaScript with no build step.

- `index.html` — homepage
- `css/tokens.css` — design tokens (colour, type, spacing, motion)
- `css/base.css`, `css/components.css`, `css/home.css` — styles
- `js/main.js` — interactions and motion (GSAP, ScrollTrigger and Lenis are in `js/vendor/`)
- `images/` — photographs and logos; optimised WebP copies in `images/opt/`

To preview locally, serve the folder with any static server, for example `python -m http.server 4173`.
